# Roadmap

## Locked foundation

- stable 4 KiB NTSC ROM baseline
- 128-color TIA rainbow
- scanline-aware kernels
- P0 joystick input
- reliability/regression loop

## Near term

- make the compiler source tree complete and reproducible
- formalize parser and semantic validation
- formalize the hardware IR
- expand static ROM validation
- add regression fixtures
- improve diagnostics

## Later

- sprites and playfield graphics
- additional input devices
- sound
- collision and game state
- memory abstractions
- additional ROM sizes/bankswitching

New power remains subordinate to the reliability goal.
